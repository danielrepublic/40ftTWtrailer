# Agents

This repository is maintained as an ETS2 Blender/SCS project. Start with the
domain and workflow documents before changing source or build files.

## Required reading

- `CONTEXT.md` for domain vocabulary and current model decisions.
- `docs/agents/workflow.md` for the repository-specific operating rules.
- `docs/MODEL_NAMING_V1_1.md` before touching Blender object or locator names.

## Agent skills

### Issue tracker

GitHub Issues, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout. See `docs/agents/domain.md`.
